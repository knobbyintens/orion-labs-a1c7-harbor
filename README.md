# Project Harbor

Official implementation of the paper **"Federated Anomaly Detection for Industrial Sensor Networks"** (`ORL-2024-002`).

## Repository Status

**✅ Released** — The code accompanying this paper is publicly available under the Apache License 2.0.

## Abstract

A federated learning approach for detecting anomalies in heterogeneous industrial sensor deployments while keeping raw telemetry on-device.

## Installation

```bash
pip install -r requirements.txt
```
